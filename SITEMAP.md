# Sitemap for Google Search Console

Your sitemap is auto-generated by Next.js at:

**https://mhentor.netlify.app/sitemap.xml**

It is also linked from `robots.txt`:
**https://mhentor.netlify.app/robots.txt**

## Submit in Google Search Console (easy steps)

1. Open [Google Search Console](https://search.google.com/search-console)
2. Select your property: `https://mhentor.netlify.app`
3. Left menu → **Sitemaps**
4. Under “Add a new sitemap”, type exactly:

   ```
   sitemap.xml
   ```

5. Click **Submit**

## Check it works

Open this URL in your browser:

https://mhentor.netlify.app/sitemap.xml

You should see an XML list of your pages (Home, About, Projects, etc.).

## Notes

- Verify the site in Search Console first (HTML meta tag), then submit the sitemap.
- Use the same URL style as your GSC property (`https://mhentor.netlify.app` — no `www`, with `https`).
- Netlify env (optional): `NEXT_PUBLIC_SITE_URL=https://mhentor.netlify.app`
